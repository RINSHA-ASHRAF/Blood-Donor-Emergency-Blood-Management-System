
# 🩸 Blood Donor & Emergency Blood Management System

## 📌 Project Overview

The Blood Donor & Emergency Blood Management System is a Python-based desktop application developed to simplify blood donor management and blood stock tracking.

The application provides an easy-to-use graphical interface to manage donor information, monitor blood availability, and handle emergency blood requests.

## ✨ Key Features

- Register and manage blood donor details.
- Search donors based on blood groups.
- Update and delete donor information.
- Add and view available blood stock.
- Handle emergency blood requests.
- Dashboard to monitor registered donors and available blood units.
- Store and manage records using file handling.
- User-friendly graphical interface using Tkinter.

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Tkinter (GUI)
- File Handling

## ▶️ How to Run the Project

1. Install Python on your system.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python blood_management_gui.py
```

The main objective of this project is to provide a simple desktop application for managing blood donors, tracking blood stock, and handling emergency blood requirements.
